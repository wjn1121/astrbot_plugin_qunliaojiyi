# 🧠 群聊记忆 · 人格养成

> 让 bot 记住两件事：**这个群怎么说话**，和**这个人在我这儿是谁**。

`1.5.0` · AstrBot `>=4.29.1` · aiocqhttp · MIT · 默认配置下**不增加任何 LLM 调用**

---

## 它和别的「记忆插件」不一样在哪

大部分记忆插件做的是「把聊天存进向量库，回复前检索相似片段」。那套做法对**问答**有效，
对**群聊**有两个硬伤：每次检索都要发 embedding 请求，而且检索出来的是「说过的话」，
不是「这个群该怎么说话」。

这个插件走的是另一条路：

| | 常见向量记忆 | 本插件 |
|---|---|---|
| 记什么 | 原始对话片段 | 「情境 → 表达」的说话方式，和关于某个人的结构化事实 |
| 怎么取 | 每轮向量检索 | 触发词本地匹配 + 相关度打分，**多数轮次 0 请求** |
| 注入位置 | 常塞进 system prompt | `extra_user_content_parts` + `mark_as_temp()`，**不碰 system prompt** |
| 对缓存 | 每轮破坏前缀缓存 | 前缀缓存仍命中，DeepSeek 下价差 7~30 倍 |
| 对人的理解 | 检索到就算 | 三层：关系（亲疏）+ 事实（发生过什么）+ 画像（他是谁） |
| 会不会忘 | 通常不会 | 会。三档记忆各有寿命，遗忘天数可在面板调 |

一句话：**它不是「聊天记录搜索」，是「养成」。**

## ⚡ 三分钟上手

**1. 安装**

| 方式 | 步骤 |
|---|---|
| 市场（推荐） | AstrBot WebUI → 插件市场 → 搜「群聊记忆」→ 安装 |
| 手动 | 把仓库放进 `AstrBot/data/plugins/`，WebUI 插件页点重载 |
| 依赖 | **不需要额外 pip 包**。`quart` / `aiohttp` 都是 AstrBot 自带的 |

要求 AstrBot `>=4.29.1`（用到了 `after_message_sent` 钩子）。低于这个版本会在加载时被拦下。

**2. 必填两样**

| 配置 | 位置 | 说明 |
|---|---|---|
| 主人 QQ | 参数 → 👑 全局 | 填你自己的 QQ。它一处生效、四个模块共用（关系不封顶 / 事实 300 条 / 私聊学习 / 跳过清理） |
| 群聊学习 | 参数 → 👑 全局 | 默认已开。进群就学是主功能 |

**3. 想更强的体验，再开两个开关**（默认都关，因为都涉及「对人」的数据）

| 开关 | 默认 | 开了会怎样 |
|---|---|---|
| 关系状态 `bond.enabled` | **关** | 按 QQ 记好感、亲疏五档、称呼 |
| 事实记忆 `facts.enabled` | **关** | 记住「他下周三交论文」「别叫他老弟」这类事 |

**4. 等它攒**

群风格要攒够 30 条新消息才学第一次；事实和画像要攒够几条才会出现。
装完当天看不到东西是正常的，**两三天后**面板里就开始有内容了。

## 🧩 三层记忆（插件的骨架）

```
群消息 ──► 学习（攒够 30 条才发一次请求）
             │
             ├─► ① 群风格     「这个群怎么说话」        每条带原文证据，权重跨轮累积
             │
             ├─► ② 每个人的事实 「他下周三交论文」      按 QQ 号唯一，三档熟练度，会忘
             │        │
             │        └─► ③ 个人画像 「他是谁」        把事实沉淀成一段概述，字数按好感给
             │
             └─► 关系           「我跟他多熟」          千分制好感，自然衰减，越熟越难涨
                          │
                          ▼
                    每轮回复前注入（本地拼装，零网络请求）
```

### ① 群风格：增量累积，不是每轮重写

- 每攒够 **30 条新消息**、且距上次学习超过 **30 分钟**，才发一次请求，**只发新攒的那部分**
- 学到的按「情境 → 表达」入库：`看到离谱内容时感叹 → 爱用「绷不住了」`
- 措辞变体自动合并，权重跨轮次累加，库越学越厚而不是每次推倒重来
- 每条必须带**本轮原文证据**，程序做子串校验，对不上就丢——防模型编造
- 新条目要过入库自检 + 两轮确认才生效，长期不用的按时效自动降级归档
- 上限：稳定风格 40 条 / 场景化 20 条 / 手动记忆 50 条，超出按熟练度淘汰

注入时先做**触发词本地字符串匹配**，命中就不发向量请求；真要发也带 2 秒硬超时，超时降级关键词匹配。

**手动加记忆**：自动学习靠猜，猜不准的地方就自己写。三个入口——会话卡片的 `+ 手动记忆`、
添加弹窗里的「批量粘贴」（一行一条：`内容|场景|触发词`）、顶部 `➕ 新建会话记忆`。

| | 例子 |
|---|---|
| ✅ 好 | 群友互怼时不解释、直接回怼，被怼也不生气 |
| ✅ 好 | 禁用谐音梗和网络流行语 |
| ❌ 差 | 这个群很欢乐（太抽象，模型无处下手） |
| ❌ 差 | 群友叫小明、小红（是事实不是风格，应该走事实记忆） |

手动记忆存在独立文件，单条 ≤100 字、单会话最多 50 条，**不参与跨群注入**（群专属黑话扩散到别的群会串味）。

### ② 每个人的事实：按 QQ 号唯一、三档、会忘

- **桶键是纯 QQ 号**：同一个人在这个群、那个群、私聊里都是同一份记忆。
  在 A 群说过的事，到 B 群照样记得
- **三档（核心 / 深层 / 浅层）按熟练度自动落位**：

  `熟练度 = 提到次数 55% + 重要性 30% + 新鲜度 15%`

  | 档位 | 门槛 | 待遇 |
  |---|---|---|
  | 核心 | ≥70 分（约提 3 次） | 逐条注入、不归档、降档最慢 |
  | 深层 | ≥52 分（约提 2 次，或 1 次但很重要） | 逐条注入 |
  | 浅层 | 其余 | 按类合并成一行注入，省 token |

- **会忘**，而且三档寿命不同（面板可调）：

  | 档位 | 多久没提就… | 默认 |
  |---|---|---|
  | 浅层 | 归零 → 归档（不再注入，面板里还查得到） | 15 天 |
  | 深层 | 掉回浅层 | 30 天 |
  | 核心 | 掉成深层 | 60 天 |

- **存储上限按好感分档**：不待见 5 / 陌生 20 / 熟悉 40 / 亲近 60 / 老友 100，**主人 300 条**
- **四种类型**：`fact` 长期事实 / `event` 有时间的安排 / `preference` 偏好 / `boundary` 明确边界
- `boundary` 不衰减、优先注入——「别叫我老弟」这种事，记错一次就够烦，忘掉比记错更糟
- **敏感信息硬黑名单**：密码、证件、银行卡、验证码、手机号、住址、密钥命中即丢，且不记录内容
- 对方问「你还记得吗」但确实没记忆时，明确说想不起来，**不编**

> 存储上限 ≠ 注入配额。存 300 条和存 20 条，**每轮注入的都是配额内那几条，token 完全一样**。
> 存得多不花钱，只有进 prompt 的才花。

### ③ 个人画像：事实沉淀成「这个人是谁」

每轮注入时单独一段：

```
你记得关于这个人的事：
【画像】他是群里折腾 bot 的技术型角色，长期混二次元手游，碧蓝航线 150 多级，
常自嘲抽卡不出货；说话实在、带点自嘲，是群里既干活又闲聊的那类人…
【具体的事】
- 事件：这周末打算优先完善 skill，在改亲密度设置的功能
- 事实：近期工作忙，已好几天没开游戏，没买通行证
```

画像答「他是谁」，事实答「他最近在干嘛」。**字数按好感给**，这是它不炸 token 的关键：

| 档位 | 不待见 | 陌生 | 熟悉 | 亲近 | 老友 | 主人 |
|---|---|---|---|---|---|---|
| 画像上限 | 0 | 80 字 | 130 字 | 190 字 | 260 字 | **520 字** |

- 单个 QQ 可以在面板里单独改上限（填 0 恢复档位默认，硬顶 800）
- **重写很低频**：事实新增 ≥2 条 **且** 距上次 ≥24 小时，每天最多 6 人（≈5000 token/天）
- **画像已经概括过的事实不再重复注入**（本地 2-gram 比对，包含率 ≥65% 判定），省一遍字数
- **人工补充段**：你手写的永远排最前、自动重写不覆盖。写「他是我室友，别调侃学历」这种，
  模型总结一百字都不如这一句
- 拿不到模型 / 超时就退回本地按类拼装，重写是后台任务，不阻塞回复

### 关系：把三层绑到「人」上

**默认关**。开了之后按 QQ 号记好感，全局累计，但阶段按当前场合判：

| 档位 | 门槛 | 群聊能到吗 |
|---|---|---|
| 不待见 | < 0 | 能（被骂） |
| 陌生 | 0 | 能 |
| 熟悉 | 200 | 能（群聊封顶） |
| 亲近 | 500 | 只有私聊 |
| 老友 | 800 | 只有私聊 |

一个 bot 在五十人群里对谁都「很熟」，那是客服不是亲近。

**好感怎么涨**：

```
增量 = 10（基准）× 群聊 0.5 × 被动 0.25 × 0.5^(当前好感/300)
```

- **只认「bot 回过」的交互**：判定挂在回复真正发出之后。群里两个人聊得再热闹、bot 一个字没接，
  一分都不涨——那反映的是谁打字快，不是关系
- **15 分钟只判一次**：中间说多少句都不算
- **被动轮 ×0.25**：别人来找 bot、bot 回复这类只给四分之一。群里随口搭一句就算一轮，
  按原值 40 轮就「熟悉」了，那是刷出来的。主动插话那一轮不走这个系数
- **指数曲线**：越往后越难，0 → ×1.0、300 → ×0.5、600 → ×0.25、900 → ×0.125
- **日上限 80 点**：最硬的闸门，防连聊一整天一次刷到老友
- **会忘**：`1-(t/30)²`，7 天 -5%、半月 -25%、一月归零回落陌生。读的时候按时间差算，不起定时任务
- **会记仇**：被明确骂一句扣 10（群聊减半，下限 -100）。只认 20 字以内、带「你」的歧义词——
  「这游戏真垃圾」不算，「你就是个垃圾」才算。**不用 LLM 判定**

实测节奏（群聊被动、15 分钟冷却）：熟悉 ≈ 2.3 天、亲近 ≈ 8 天、老友 ≈ 19.5 天。

**亲密度还能影响记忆量**：关系段 100~300 字、事实 1~10 条，按档位给。
陌生人只给 2 条、主人给 10 条——省钱是次要的，主要是别对刚说两句话的人报出他半年前的私事。

## 🗣 主动回复（默认关）

唯一会**凭空产生请求**的功能。判定全程本地，零额外 token：

```
p = 基准 × (1 − 0.7×群热度) × (1 + 0.4×(1−群热度)) + 0.5 × 接话黏性
```

- **群热度**：最近 120 秒的消息数。越热闹越压低，把插话让给人说话；越冷清反而略微抬高——
  安静时冒个泡是捧场，热闹时插话是噪音
- **接话黏性**：bot 刚说完话、别人接着讲（3 分钟内），或有人抛问题（「有没有人知道」「求推荐」），
  攒一个半衰期 5 分钟的分。bot 自己说完先降一截——「我说完了，轮到你们」
- 冷却期也照样积累黏性，否则「有人接话」这个信号等冷却过了就失效了

面板顶部**五档一键切换**（一次改 5 个参数，它们是互相咬合的）：

| 档位 | 参与概率 | 冷却 | 日限 | 约 token/天 |
|---|---|---|---|---|
| 🛡 安静 | 0.05 | 60 min | 3 | 0.5 万 |
| ⚖️ 平衡 | 0.15 | 30 min | 8 | 1.2 万 |
| 🔥 活跃 | 0.35 | 10 min | 20 | 3 万 |
| ⚡ 高频 | 0.55 | 5 min | 40 | 6 万 |
| 🚀 常驻 | 0.80 | 3 min | 70 | 10 万 |

日限是最硬的闸门：概率写 0.8 也只管「每次窗口敢不敢说」，一天说满就到顶。
此外还有 12 层本地闸门（静默时段、冷清阈值、连续没人接话的退避、25 秒硬间隔等）。

## 🔍 联网搜索接管（默认关）

插件自己挂搜索工具，而不是让主模型随手搜：

- 每群每天限次（默认 20 次），**挂载前就按配额决定给不给工具**，不是调用了才拒绝
- 默认 DeepSeek 搜索，约 ¥0.005/次；也支持 Brave / Tavily 等
- 只取摘要不取整页正文——正文一条可能就是几千 token

## ✍️ 输出层（去模型腔默认开）

改的是**已经生成好的那条回复**，不产生任何 LLM 调用：

- **去模型腔**（默认开）：删「作为一个 AI」「希望这对你有帮助」「随时告诉我」，破折号换逗号
- 压连续标点、去 markdown、长回复按句拆条（三项默认关）
- 代码块、行内代码、URL 一律不碰；含代码或链接的回复不拆条；清理后变空自动退回原文

## 🎛️ 面板

左侧八个页：

| 页面 | 干什么 |
|---|---|
| 📊 概览 | 运行状态、主人是谁、群聊/私聊学不学、累计花了多少 |
| 📚 学习库 | 按群 / 私聊看学到了什么，可批准、否决、钉住、删除，能展开证据原文 |
| 🎭 关系与输出 | 好感档位、事实记忆与个人画像、输出层调试台 |
| 🧬 人格档案 | 每群一份 markdown：自动段随学习更新，人工段永远归你 |
| 🔍 注入预览 | 输入一句话，看这轮实际会往 prompt 里塞什么（不改任何数据） |
| 💬 会话与特征 | 每个会话的原始特征明细，可逐条编辑、删除、单独开关 |
| 💸 Token 消费 | 今天的 24 小时分布、近 7 天趋势、按会话拆分 |
| ⚙️ 参数 | 43 项分九组热调，改完下一轮生效，不用重启 |

几个设计上的取舍：

- **三个列表统一成 Excel 式列头筛选**：每个字段一个按钮，各自展开搜索 / 多选 / 排序，
  列头标 `●` 表示有筛选、`↑↓` 表示排序中
- **能删，但都要二次确认**；置顶的一律不能删，那一行**干脆不渲染删除按钮**
- **每个按钮都有悬停注解**：写清「按下去会发生什么 / 花不花钱 / 能不能恢复」
- **每条参数都有「默认 X」徽标 + token 箭头**：`↑↑↑` / `↑↑` / `↑` / `↓` / `token 0`
- **面板按模块控高**：数据会长的地方限高滚动，参数页不限（固定项数，加滚动反而多一层框）

## 🤖 命令

**所有人可用**（需先开关系）

| 命令 | 作用 |
|---|---|
| `/关系` | 看和你的关系进度：认识多少天、聊过多少轮、离下一档还差多少 |
| `/称呼 <名字>` | 设定 bot 怎么叫你；不带参数则清除 |
| `/记得` | 看关于自己的全部记忆（带编号、状态、类型） |
| `/记得 <内容>` | 手动记一条，直接生效 |
| `/忘掉 <编号或关键词>` | 立即删除 |

**要求管理员**（AstrBot 全局 `admins_id` + 插件配置 `admin_extra_users`）

| 命令 | 作用 |
|---|---|
| `/风格状态` | 本群风格强度、特征条数、主动回复状态、今日搜索次数、今日消耗 |
| `/学习风格` | 立即对当前会话学一次（攒够 30 条才行） |
| `/清空风格` | 只清**学习产出**，不碰手动记忆和待学习消息 |
| `/清空记忆` | 只清**面板手动添加的记忆**，不可恢复 |
| `/清空记录` | 只清**待学习消息缓冲** |
| `/确认清空` | 执行挂起的「清空全部」，60 秒内有效 |

`/清空风格 全部` 会挂起一个待确认操作，期间发 `/确认清空` 才真的清四类数据。
只有 `全部` 需要确认，单清某一类直接生效。

## ⚙️ 配置速查

完整 43 项在面板「参数」页（带搜索框），这里只列最常动的：

| 配置 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关。关掉后不收集、不学习、不注入 |
| `owner_ids` | 空 | 主人 QQ，一处生效四模块共用 |
| `learn_group_enabled` | `true` | 群聊学习（全局） |
| `learn_private_enabled` | `false` | 私聊学习（主人私聊自动开） |
| `min_history_for_analysis` | `30` | 攒够多少条才允许学习 |
| `analysis_interval_seconds` | `21600` | 两次学习最小间隔（6 小时） |
| `trait_max_total` | `150` | 特征总上限（注入每轮只用 5 条，多了只是拖慢 prompt） |
| `reply_max_chars` | `0` | 被动回复字数上限，0 = 不限 |
| `active_reply_enabled` | `false` | 主动回复 |
| `active_reply_chance` | `0.15` | 参与概率基准（实际还会被群热度压低、被接话黏性抬高） |
| `bond.enabled` | `false` | 关系状态 |
| `bond.growth_per_turn` | `10` | 好感基准增量 |
| `bond.passive_growth_factor` | `0.25` | 被动轮系数（设 1.0 = 取消这条规则） |
| `bond.growth_curve_scale` | `300` | 指数曲线刻度（设 0 = 退回线性） |
| `bond.daily_gain_cap` | `80` | 每天最多涨多少点 |
| `bond.growth_cooldown` | `900` | 好感变化冷却（秒） |
| `facts.enabled` | `false` | 事实记忆 |
| `facts.max_per_user` | `20` | 陌生档存储上限基准（其余档按倍率缩放） |
| `fact_shallow_days` | `15` | 浅层遗忘天数 |
| `fact_deep_days` | `30` | 深层降档天数 |
| `fact_core_days` | `60` | 核心降档天数 |
| `profile_enabled` | `true` | 个人画像（事实开了才有意义） |
| `profile_daily_cap` | `6` | 每天最多重写几个人的画像 |

## 💸 成本

**默认配置（关系、事实、主动回复全关）**：只有学习链路花钱。

| 项目 | 量级 |
|---|---|
| 一次学习 | 约 30 条消息 + 已有特征 + 抽取指令 ≈ 1 万输入 / 1 千输出 |
| 触发频率 | 每 30 条新消息一次，且间隔 ≥30 分钟 |
| 一个中等活跃群 | 一天约 3~8 次 ≈ 0.1~0.3 元（DeepSeek 计价） |
| 注入 | **0 元**（本地拼装，不发请求） |

**开了可选功能之后**：

| 功能 | 增量 |
|---|---|
| 关系 | 0（纯本地拼一段话） |
| 事实抽取 | 0 额外调用（并进同一次学习请求，prompt 多约 400 字） |
| 画像重写 | 每天最多 6 人 ≈ 5000 token |
| 主动回复 | 按档位 0.5~10 万 token/天 |
| 联网搜索 | 每群每天限次，约 ¥0.005/次 |

省钱的三条根本设计：

1. **注入走 temp 消息，不碰 system prompt** —— 保住 DeepSeek 前缀缓存，价差 7~30 倍
2. **能本地算的绝不发请求** —— 触发词匹配、相似合并、去重、好感判定全在本地
3. **动态内容不进 system prompt** —— 风格、关系、事实、画像每轮都变，进了就等于每轮打掉缓存

| `metrics.json` | 累计统计 |

| `token/YYYY-MM-DD.json` | 按天账单，保留 7 天 |

**隐私边界**：

- 全部数据只在本地，插件不上传任何东西（除了你自己配的模型 / 搜索接口）
- 事实抽取的 prompt 里写明：只记对用户有利的（偏好、约定、重要事件、明确边界），

- **手动记忆独立存储**：自动学习在代码层面就没有改它的路径

## 🔌 Web 接口

面板自己就是这几个接口的客户端，二次开发可以直接调。路由前缀是插件名：

| 方法 | 路由 | 说明 |
|---|---|---|
| `GET` | `/status` | 全局统计、会话列表、注入名额、已知平台前缀 |
| `POST` | `/manage` | 全部写操作，靠 body 里的 `action` 区分 |
| `POST` | `/preview` | 传会话 + 一句话，返回这轮实际会注入的文本 |
| `POST` | `/import` | 导入 `backup/<目录>/` 下的备份，`mode=merge` / `replace` |
| `GET` | `/export` | 导出全部数据（含关系、事实、画像） |
| `GET` | `/traits` | 学习库：带 `session_id` 看单群，不带就跨群汇总 |
| `POST` | `/review` | 审核：`approve` / `reject` / `restore` / `pin` / `unpin` / `delete_trait` |
| `GET` | `/facts` | 按 QQ 号的事实与画像 |
| `POST` | `/facts` | `pin` / `pin_user` / `set_tier` / `prune` / `merge` / `save_profile` / `rewrite_profile` |
| `GET` | `/persona` | 人格档案：概览或某群全文（自动段 + 人工段） |

涉及会话的 `action` 都要求 `session_id` 形如 `平台实例:GroupMessage:群号`，
格式不对直接拒绝——防止写进一个永远不会命中的僵尸会话。

## ❓ FAQ

**Q：装完一天了，面板里什么都没有？**
群风格要攒够 30 条新消息才学第一次，事实要攒几条才会出现。另外学习间隔默认 6 小时，
新装时会有 5 分钟启动延迟。等两三天是正常的。

**Q：它会不会每轮都在后台发请求？**
不会。注入是纯本地拼装。唯一发请求的是「学习」（每 30 条新消息一次）和开了主动回复之后的插话。

**Q：为什么不用向量库？**
群聊要的不是「找相似句子」，是「这个群怎么说话」。向量检索每轮都要发 embedding，
而且检索到的是原话，不是表达方式。触发词本地匹配在多数轮次能解决，且 0 请求。

**Q：好感涨得特别慢，是不是没生效？**
是设计。只认 bot 回过的交互、被动 ×0.25、指数曲线、日上限 80。想快就调
`passive_growth_factor`（回 1.0）和 `growth_curve_scale`（设 0 退回线性）。

**Q：记忆会不会越攒越贵？**
不会。存储上限和注入配额是两件事：存 300 条和存 20 条，每轮注入的都只是配额内那几条。
会涨价的是「每轮注入的字数」，那由关系档位和画像上限控制。

**Q：能不能只让某个群不学？**
能。学习库每行有「学习中 / 不学」开关，会话级覆盖优先于全局开关。

**Q：换群之后它还记得我吗？**
事实和画像是按 QQ 号唯一的，换群照样记得。群风格是按会话的，因为每个群的说话方式不同。

**Q：手动加的记忆会被自动学习删掉吗？**
不会。手动记忆存在独立文件，自动学习在代码层面就没有改它的路径。

**Q：怎么备份 / 迁移？**
面板「导出数据」下一个 JSON（含关系、事实、画像），新机器「导入备份」即可。
也可以直接备份整个 `plugin_data/astrbot_plugin_qunliaojiyi/` 目录。

**Q：支持 QQ 之外吗？**
代码只针对 aiocqhttp（OneBot v11）测过。其他平台理论上能跑，但主动回复、拍一拍这类
平台特性不保证。
